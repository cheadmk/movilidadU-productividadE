# Urban Mobility & Economic Indicators Analysis – Sprint 5

Este repositorio contiene el análisis realizado durante el Sprint 5, enfocado en explorar la relación entre indicadores de movilidad urbana y variables económicas en distintas ciudades durante el año 2024.

El proyecto integra datos de tráfico urbano provenientes de TomTom con indicadores económicos de ciudades recopilados por la OCDE, permitiendo analizar patrones de congestión, calidad del aire y desempeño económico.

## 📂 Contenido del repositorio

* `S5_ladb_mobility_economy_project_student_FINAL.ipynb`
  → Notebook principal con limpieza de datos, validaciones, análisis exploratorio, visualizaciones e interpretación de resultados.
